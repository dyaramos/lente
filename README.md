## About the Project

Lente is a fictional camera store showcasing a modern, Y2K/holographic-inspired design with:

- Responsive layout (desktop, tablet, mobile)
- Hero slideshow
- Featured categories
- Best Selling product grid
- Holiday Sale banner with countdown
- About Us section with multilingual text (Chinese, Japanese, Korean)
- Interactive product cards with hover effects

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables, Media Queries)
- JavaScript (vanilla)
- [Lucide Icons](https://lucide.dev/)

## Purpose

This project was built to practice and demonstrate:

- Semantic HTML structure
- Responsive web design
- CSS gradients, glassmorphism, and modern UI techniques
- JavaScript toggles and DOM manipulation
